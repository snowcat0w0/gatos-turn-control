# Gato's Turn Control (gatos-turn-control)

이 모듈은 AI를 써서 만들었어요.

## 이게 뭐예요?

Foundry VTT에서 전투할 때 "누구 차례인지"를 더 똑똑하게 돌려 주는 모듈이에요. 쓰러진 적의 차례를 알아서 건너뛰고 움직일 수 없는 캐릭터의 턴을 자동으로 넘겨요. 내 차례를 뒤로 미루는 "지연"도 할 수 있어요.

어떤 게임 시스템에서도 써요. Pathfinder 1e(PF1)에서는 빈사, 혼란, 안정화 같은 PF1 규칙이 더 붙어요.

이 폴더의 모듈은 Foundry VTT 14 버전용이에요(`foundry-v14` 브랜치). 13 버전을 쓰면 `master` 브랜치를 받아요.

## 먼저 준비할 것

이 모듈은 **gatos-lib** 모듈이 있어야 돌아가요. 둘 다 설치하고 둘 다 켜 주세요. gatos-lib가 꺼져 있으면 월드에 들어갈 때 경고가 떠요.

## 설치하는 법

1. Foundry 첫 화면(설정 화면)에서 **애드온 모듈** 탭을 열고 **모듈 설치**를 눌러요.
2. 창 맨 아래 **매니페스트 URL** 칸에 아래 주소를 붙여 넣고 **설치**를 눌러요.

   ```
   https://raw.githubusercontent.com/snowcat0w0/gatos-turn-control/master/module.json
   ```

3. "gatos-lib도 함께 설치할까요?" 하고 물어보면 **예**를 눌러요. 이미 있으면 안 물어봐요.
4. 월드에 들어가서 **게임 설정 → 모듈 관리**에서 **Gato's Library**와 **Gato's Turn Control**을 둘 다 체크하고 저장해요.

주소로 설치가 안 되면 [Releases](https://github.com/snowcat0w0/gatos-turn-control/releases) 페이지에서 `gatos-turn-control.zip`을 받아 풀고 그 폴더를 `Data/modules/gatos-turn-control`에 넣어도 돼요.

## 할 수 있는 것들

### 턴 제외 (전투에는 남고 차례만 건너뛰기)

전투 추적기에서 전투원을 우클릭하고 **턴 제외 전환**을 누르면(GM만), 그 전투원은 전투에 남아 있지만 차례가 돌아오지 않아요. 추적기에서는 흐리게 줄이 그어져 보여요. 전투에서 빠진 게 아니라서 나중에 경험치를 나눌 때는 그대로 들어가요.

이런 때는 알아서 제외돼요(설정에서 바꿀 수 있어요).

- 전투불능(해골)이나 사망 상태가 붙었을 때.
- HP가 사망 기준 아래로 내려갔을 때. 기본 설정에서는 플레이어 캐릭터가 아닌 경우에만 그래요.

### 죽은 토큰 숨기기

죽어서 턴 제외된 토큰은 플레이어 화면에서 사라져요. GM에게는 반투명하게 보여요. 되살아나거나 제외를 풀면 다시 나타나요. 전투가 끝나면 숨긴 토큰을 다시 보여 줘요. 전리품을 챙길 수 있게요.

### 잡몹 대표 토큰

고블린 다섯 마리를 토큰 하나로 이니셔티브를 돌릴 때, 그 토큰이 죽으면 같은 종류의 살아 있는 고블린 중 전투에 안 들어 있는 고블린이 그 자리와 우선권을 이어받아요. 죽은 고블린은 턴 없는 전투원으로 남아요.

### 움직일 수 없으면 자동으로 턴 넘기기

턴이 시작될 때 기절, 수면, 마비처럼 행동할 수 없는 상태가 붙어 있으면 채팅에 이유를 남기고 턴을 자동으로 넘겨요. 어떤 상태가 그렇게 되는지는 **모듈 설정 → 턴 종료 상태이상** 메뉴에서 체크해요.

모두가 행동 불가이면 끝없이 돌지 않도록 경고만 남기고 멈춰요. 이전 턴으로 되돌린 뒤에는 자동으로 넘기지 않아요.

PF1에서는 이것도 돼요.

- HP가 0보다 작고 안정 상태가 아니면 **빈사**, 비살상 피해가 현재 HP보다 많으면 **기절**로 봐요.
- 빈사 카드에 **안정화 판정 굴리기** 버튼이 생겨요(DC 10 건강, 음수 HP만큼 페널티).
- **혼란** 상태면 턴 시작 때 d%를 굴려 행동표를 보여 주고 헛소리(26~50)가 나오면 턴을 넘겨요.

### 지연 (내 차례를 뒤로 미루기)

PF1 코어 룰북의 "지연" 규칙이에요. 다른 시스템에서도 같은 방식으로 돼요.

- 내 턴에 **모래시계** 버튼(추적기 아래 버튼이나 우클릭 메뉴에도 있어요)을 누르면 턴이 넘어가고 "지연 중" 표시가 붙어요.
- 다른 사람 턴에 **▶ 지금 행동**을 누르면 그 사람보다 먼저 행동하고 우선권이 그 자리로 바뀌어요. **⏩ 현재 턴이 끝나면 행동**은 예약이에요. 지금 사람이 턴을 끝내는 순간 끼어들어요.
- 지연한 채로 원래 내 차례가 다시 오면 지연은 사라지고 평소대로 턴이 시작돼요. 다시 지연할 수 있어요.
- 행동 불가 상태에서는 지연할 수 없어요.
- 플레이어도 자기 캐릭터로 쓸 수 있어요. 처리는 GM 컴퓨터가 하니까 GM이 접속해 있어야 해요.

## 설정

**게임 설정 → 모듈 설정 → Gato's Turn Control**에서 바꿔요. 전부 월드 설정이라 GM이 바꾸면 모두에게 적용돼요.

| 설정 | 처음 값 | 참고 |
|---|---|---|
| 전투불능/사망 전투원 턴 제외 | 켬 | |
| HP로 사망 판정 | 플레이어 소유가 아닌 액터만 | |
| HP 경로 / 사망 기준 HP | `system.attributes.hp.value` / 0 | PF1이 아닐 때만 보여요 |
| 사망 + 턴 제외 토큰 숨기기 | 켬 | |
| 전투 종료 시 숨긴 토큰 다시 표시 | 켬 | |
| 대표 토큰 사망 시 같은 종류로 턴 넘기기 | 켬 | |
| HP로 빈사/기절 판정 | 켬 | PF1만 |
| 행동 불가 디버프 자동 턴 종료 | 켬 | |
| 턴 종료 상태이상 | 시스템 기본 목록 | 체크리스트 메뉴 |
| 혼란 자동 판정 | 켬 | PF1만 |
| 지연 채팅 알림 | 켬 | |
| 자동 턴 종료 대기(ms) | 600 | |

## 알아두기

- 전투 추적기 버튼은 Foundry 기본 추적기 모양에 맞춰 붙어요. 추적기를 완전히 새로 그리는 시스템(예: PF2e)에서는 버튼 대신 우클릭 메뉴를 쓰세요.
- PF1은 누군가를 건너뛸 때 직전 전투원의 "턴 종료" 버프 처리를 빼먹는 경우가 있어서 이 모듈이 그 부분을 대신 처리해요.
- 매크로를 만드는 사람은 `game.modules.get("gatos-turn-control").api`에서 `delay`, `resumeNow`, `queueAfterCurrent`, `cancelDelay`, `toggleNoTurn` 같은 함수를 쓸 수 있어요.
