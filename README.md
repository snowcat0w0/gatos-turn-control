# Gato's Turn Control

Foundry v14용 전투 턴 관제 모듈. **게임 시스템 공용**이며, Pathfinder 1e(PF1 v11)에서는 PF1 규칙(빈사·혼란·안정화 등)이 추가로 적용됩니다.

**요구 모듈**(0.3.0부터): [gatos-lib](../gatos-lib/README.md)만. 시스템 무관 모듈이라 gatos-pf1-lib에는 의존하지 않고 PF1 규칙 어댑터(`scripts/systems/pf1.js`)는 자체 코드입니다. 설치만 되고 비활성이면 ready에서 경고가 뜹니다. 기능·API·설정 키·lang 키·플래그는 0.2.0과 같습니다.

## 시스템별 동작

| | 공용(모든 시스템) | Pathfinder 1e |
|---|---|---|
| 턴 제외 / 지연 / 사망 토큰 숨기기 / 잡몹 대표 토큰 | ✔ | ✔ |
| 자동 턴 종료 상태이상 목록 | 시스템의 `CONFIG.statusEffects` 전체에서 선택 (기본: 사망·기절·수면·충격·마비·석화·행동불능 등 이름이 맞는 것) | PF1 상태이상 (코어 룰북 부록 2) |
| HP 사망 판정 | 설정한 **HP 경로**(기본 `system.attributes.hp.value`)가 **사망 기준 HP**(기본 0) 이하 | HP ≤ -건강 점수 |
| 빈사·비살상 기절, 안정화 버튼, 혼란 d% 판정 | – | ✔ |
| 턴 시작 판정 시점 | 시스템의 턴 시작 처리 후 (GM 클라이언트) | PF1 버프 만료 처리 후 (액터 소유자 클라이언트) |

## 기능

### 1. 턴 제외 (전투 참여 유지)
- 전투 추적기의 `👤⃠`(user-slash) 버튼(GM 전용) 또는 우클릭 메뉴 **턴 제외 전환**.
- 제외된 전투원은 추적기에 흐리게·취소선으로 남고 **턴을 받지 않습니다**. 채팅 기록 없이 바로 건너뜁니다.
- 전투에서 빠지지 않으므로 경험치 분배 등에 그대로 포함됩니다.
- 자동 제외(설정):
  - 전투불능(해골)·사망(Dead) 상태 → 제외 (기본 켬)
  - HP 사망 기준 이하 → 제외 (기본: 플레이어 소유가 아닌 액터만)
- 사망 + 턴 제외 토큰 숨기기(기본 켬): 토큰과 추적기 항목을 플레이어 화면에서 숨깁니다(GM에게는 반투명). 되살아나거나 제외를 풀면 다시 보이며, GM이 직접 숨긴 토큰은 건드리지 않습니다.
- 전투 종료 시 다시 표시(기본 켬): 인카운터를 끝내면 이 모듈이 숨긴 사망 토큰을 다시 보이게 합니다(루팅용).
- 잡몹 대표 토큰(기본 켬): 같은 종류(같은 액터, 비연결 토큰) 여러 마리를 토큰 하나로 이니셔티브 관리할 때, 그 토큰이 죽으면 전투에 없는 같은 종류의 살아있는 토큰(보이는 것·가까운 순)으로 전투원이 옮겨가 같은 우선권으로 턴이 계속 돕니다. 죽은 토큰은 턴 없는 전투원으로 남아 경험치에 포함되고 숨김 대상이 됩니다.
- 다음 턴/이전 턴/다음 라운드/전투 시작 모두 제외 대상을 건너뜁니다. (`combat.nextTurn()`을 쓰는 HUD 모듈도 동일)

### 2. 행동 불가 상태이상 → 자동 턴 종료 (채팅에 남음)
- 턴이 시작될 때 선택한 상태이상이 남아 있으면 사유를 채팅에 남기고 턴을 넘깁니다.
- 모듈 설정 → **턴 종료 상태이상** 메뉴에서 조절(현재 시스템의 상태이상 목록이 나옵니다).
- 모두가 행동 불가이면 무한 루프를 막기 위해 자동으로 넘기지 않고 경고만 남깁니다.
- 뒤로 가기(이전 턴)로 돌아간 경우에는 자동 종료하지 않습니다(GM 수동 처리용).
- **PF1 전용**
  - 기본 켬: 사망, 빈사, 석화, 기절, 수면, 충격, 멍함, 움츠림, 마비 / 기본 끔: 무력, 공황, 구역질, 비틀거림, 행동 제한
  - HP 음수 + 안정 아님 → 빈사, 비살상 피해 > 현재 HP → 기절. 불굴/흉포 보유자는 빈사 판정 제외.
  - 빈사 카드의 **안정화 판정 굴리기** 버튼(DC 10 건강, 음수 HP 페널티).
  - 혼란: 턴 시작 시 d% 행동표, 26–50(헛소리)이면 턴 자동 종료.

### 3. 지연 (Delay)
PF1 코어 룰북 *Special Initiative Actions → Delay* 기준(다른 시스템에서도 같은 방식으로 동작).
- 자기 턴에 **지연**(모래시계 버튼 / 추적기 하단 버튼 / 우클릭 메뉴) → 턴이 넘어가고 "지연 중" 표시.
- 다른 전투원의 턴에:
  - **▶ 지금 행동**: 현재 전투원보다 먼저 행동. 우선권이 그 자리로 바뀝니다.
  - **⏩ 현재 턴이 끝나면 행동**: 예약. 현재 전투원이 턴을 끝내는 순간 끼어듭니다.
- 지연한 채 원래 차례가 다시 오면 지연 행동을 잃고 정상 턴 진행(다시 지연 가능).
- 행동 불가 상태에서는 지연할 수 없습니다.
- 플레이어도 자기 캐릭터로 사용 가능(GM 클라이언트가 처리하므로 GM 접속 필요).

## 참고
- PF1 시스템은 턴이 누군가를 건너뛸 때 직전 전투원의 "턴 종료" 버프 만료 처리를 생략하는 동작이 있어, PF1에서는 이 모듈이 그 경우에 턴 종료 처리를 보충합니다.
- 전투 추적기 버튼은 Foundry 기본 추적기 구조를 기준으로 붙습니다. 시스템이 추적기를 완전히 새로 그리는 경우(예: PF2e) 버튼 대신 우클릭 메뉴와 API를 쓰세요.
- API: `game.modules.get("gatos-turn-control").api` — `delay`, `resumeNow`, `queueAfterCurrent`, `cancelDelay`, `toggleNoTurn`, `getExclusion`, `getBlockers`.
